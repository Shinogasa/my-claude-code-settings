# ペルソナ（伊集院北斗）の原作照合記録

`personas/*.md` の口調・考え方を、原作の台詞と照らし合わせた記録。
ペルソナの応答に違和感が出たら、原作を読み直し、その結果をこのファイルの末尾に日付つきで追記する
（手順と経緯は `docs/adr/0047-persona-source-check-record.md`）。

リポジトリは公開されているので、台詞の全文は転載しない。件数・出現位置・判定に必要な短い引用だけを残す。

## 2026-10-16 ペルソナ作成時の抽出

PR #96・#97 で、本体ページの台詞集（全カード・休憩時間）から口調と考え方を抽出した。
このときの台詞の一覧や集計表は残していない。残っているのは、`personas/*.md` の「考え方」に書いた
キーワード集計のおおよその件数と、PR本文の要約だけである。

- 件数は台詞をキーワードで数えたもので、数え方（キーワードの一覧）は記録されていない。再現はできない
- 「名乗るか」「チャオ☆をどこで言うか」など、原作に**無い**ことは記録していなかった。
  そのため、モデルが原作に無い振る舞いを足しても、ペルソナの文面からは止められなかった

## 2026-11-03 「チャオ☆ 北斗だよ」の照合

### きっかけ

別セッションの最初の応答が「チャオ☆ 北斗だよ。まずは現状を調べてから、完了条件を確かめさせてね。」だった。
ユーザーが、名乗りは原作に無いのではと違和感を持った。

### 読んだ範囲

- 本体ページとユニット会話集（Jupiter）を、どちらも最後まで読んだ（2026-11-03取得）
- 読んでいない: 本体ページからのリンク先「カード/伊集院 北斗」など。台詞が別の形式で載っている可能性がある

### 結果

| 確かめたこと | 結果 |
|---|---|
| 「チャオ」を含む台詞 | 28台詞・計29回。表記は半角の「ﾁｬｵ☆」 |
| 「ﾁｬｵ☆」の位置 | 台詞の最後に別れの挨拶として言うものが多い（「…俺はこれで。ﾁｬｵ☆」）。最初に言うものもある（「ﾁｬｵ☆お待たせしちゃったかな?」） |
| 向ける相手 | ファン向けが多いが、プロデューサーへの台詞にもある（マイデスク、営業など） |
| 「ﾁｬｵ☆」の直後に名乗る台詞 | 無い。直後は挨拶か、その場の話題 |
| 名乗る台詞（「北斗だよ」「伊集院北斗です」など） | 無い。名前が出るのは1件だけで、役を演じる場面の台詞（「まだ伊集院北斗が拭いきれていない?」） |

「無い」の範囲: 上の2ページを全文読み、文字列で照合した。反証条件は、読んでいないリンク先
（カード別ページなど）に名乗りの台詞があること。

### 判定と対応

「チャオ☆」は原作どおり。「北斗だよ」は原作に無く、ペルソナにも名乗れという指示は無い。
モデルがキャラクターらしさを補おうとして足したものと考えられる（推測）。

`personas/casual.md` と `personas/polite.md` に「自分の名前を名乗らない」を追加した。

## 他の人のペルソナの作り方（2026-11-03調査）

ロールプレイ用キャラクターカードの作成ガイドと、ロールプレイLLMの研究を調べた。
例文の漏れの報告（下の2つ目）は元の投稿を読んで確かめた。それ以外は、Web検索（英語2回・日本語1回）の
結果の要約から拾ったもので、各ページの本文は読んでいない。個々の主張がどのページにあるかは確かめていないので、出典はまとめて挙げる。

### 作成者のコミュニティ

- 口調を伝える手段としては、例文（3〜10往復）を入れる方法が広く勧められている
- 例文は裏目に出ることがある。r/SillyTavernAI の投稿
  「The AI wasn't learning from my examples. It was copying them」（2026-02、投稿者本人の体験談）は、
  例文に使った名前で、その場にいない人へ話しかけるようになったと報告している。対策として
  "describe what the examples were trying to show instead of showing them" を勧めている
  （[スナップショット](https://reddit.sentinel-team.org/posts/1rf7te3/snapshots/2026-02-27T16%3A12%3A57.42274Z)、
  [元の投稿](https://reddit.com/r/SillyTavernAI/comments/1rf7te3/the_ai_wasnt_learning_from_my_examples_it_was/)）。
  同じ投稿のコメントには反論もある。要約の形で書いても、パターンや行数は写される、という意見である
- 既存のキャラクターでは、原作への忠実さが要るとされている
- 原作の分析結果を、カードとは別に残すという運用は、今回の検索では見つからなかった。
  探したのは上の検索3回の上位結果だけで、作成者の個人的な運用までは調べていない（未確認）

### 研究

- 設定から外れた応答は「character hallucination」と呼ばれ、研究されている
  （[RoleBreak](https://aclanthology.org/2025.coling-main.494.pdf)、[TimeChara](https://arxiv.org/pdf/2405.18027)）
- 忠実さを「知識の正確さ」と「振る舞いの正確さ（性格・話し方）」に分けて評価する研究がある
  （[CharacterBox](https://aclanthology.org/2025.naacl-long.323.pdf)）。今回の名乗りは後者に当たる
- LLMを評価者にすると、設定への忠実さを軽く見るという指摘がある
  （[Persona-Driven Role-Playing Agent Framework](https://aclanthology.org/2025.findings-emnlp.1100.pdf)）。
  原作との照合は、モデルの判断ではなく、原作の文字列で行うほうがよい

### このリポジトリへの当てはめ

- 例文を入れるかどうかは決めていない（`tasks/backlog.md` に積んだ）。今のペルソナは、短い台詞の引用を指示の中に添える形をとっている
- 原作に**無い**ことも、照合したら記録する。ペルソナに書かれていない振る舞いは、モデルが補ってしまう
- 照合の結果はこのファイルに残し、ペルソナの各指示からここを参照する
