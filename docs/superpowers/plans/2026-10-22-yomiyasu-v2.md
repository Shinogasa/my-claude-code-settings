# yomiyasu v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** yomiyasuをv2.1.2へ上げ、日本語レビューを壊さずに、直した内容を「元 → 後」の対で見せる。

**Architecture:** submoduleを `vendor/yomiyasu` へ移し、`skills/yomiyasu` を入れ子の本体へのsymlinkにする（ADR 0035と同じ形）。
レビュワーを起動するときにフックが原文の写しを `~/.claude/state/jp-doc-review/sources/` に取り、リンターのラッパー
`hooks/jp-doc-lint.py` が、その写しと今のファイルで `yomiyasu_check.py run --no-record` を実行する。
レビュワーが終わったら、定義の `Stop` フック（SubagentStopに変換される）が写しを消す。

**Tech Stack:** Python 3（標準ライブラリだけ）、unittest、git submodule、Claude Code hooks

**Spec:** `docs/superpowers/specs/2026-10-22-yomiyasu-v2-design.md`

## Global Constraints

- yomiyasuは `9fabae2`（v2.1.2）に固定する
- `yomiyasu_check.py` は `run --no-record` だけを使う。`verify` は使わない
- 作業repoに `.yomiyasu/` も原文の写しも残さない
- レビュワーのBashは、今と同じくラッパー `python3 ~/.claude/hooks/jp-doc-lint.py '<ファイル>'` の1形だけ。
  spec は `run --no-record` の形まで広げてよいとしていたが、差分の検査はラッパーの中から呼ぶ（2026-10-22、ユーザーの判断）。
  理由: 写しのパスの検査、HTMLの変換、`--no-record` と実行場所を、レビュワーに任せずラッパーが決まった形で行える。ADRに書く
- レビュワーが打った形を確かめたあと、フック（`pre-tool-use-reviewer-bash`）が `updatedInput` でコマンドの末尾に
  `--session <session_key>` を足す。レビュワー自身が `--session` を打つ形は拒否する（2026-10-22、ユーザーの判断。原則レビューP03aへの答え）
- 報告の対は `元の表現 → 直した表現（理由）`。レビュー全体から重要なものだけ、件数の上限なし。重要な直しが無ければ1行でそう書く
- 作業は本体の `feat/yomiyasu-v2` で行う（動作中の設定に効くパス）
- テストは `python3 -m unittest tests.<module> -v`、最後に `bash tests/run.sh --all`

## Review Focus

1. 写しが無いまま（ユーザーが直接レビュワーを呼んだ、写しを取る前にフックが失敗した）ラッパーが呼ばれる → 差分の検査を「実行できなかった」と出して終了コード2。lintの結果は出す（Task 3）
2. 同じファイルを別のセッションが同時にレビューする → フックが足した `--session` で、自分のセッションの写しだけを使う。
   `--session` が無い（フックを通らずに呼ばれた）ときは、差分の検査を「実行できなかった」として終了コード2（Task 2・3）
3. HTMLの下書き（Confluence）→ 写しも今のファイルもテキストに直してから `--source` と `--final` に渡す。直したテキストの一時ファイルは終わったら消す（Task 3）
4. submoduleのルート（`vendor/yomiyasu/scripts/` など）をレビュワーがEditしようとする → 拒否（Task 1）
5. レビュワーが途中で落ちて `Stop` が走らない → 写しは既存の保存日数（7日）の掃除で消える（Task 2）

`<state_dir>/sources/` の下の一時ファイル（0600）に書いて渡し、`finally` で消す。`subprocess.run([sys.executable, check, "run",
"--no-record", "--source", src, "--final", final], cwd=<一時ディレクトリ>, timeout=LINTER_TIMEOUT_SECONDS)`。
cwdを一時ディレクトリにするのは、`--no-record` でも作業repoに何も作らせないため。終了コード0と1は実行できたとみなす（1は `--fail-on` 用で、ここでは付けない）。
