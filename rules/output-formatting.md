# 出力フォーマット

## URL表示ルール

- URLを含むリストを表示する際、項目名とURLは改行せず1行にまとめる
- テーブル形式よりフラットリスト形式（`- 項目名 URL`）を優先する
- 理由: ユーザーがコピペしやすい形式にするため

良い例:
```
- BFFのdev1環境を作る https://app.asana.com/1/xxx/project/yyy/task/zzz
- コイン残高APIの実装 https://app.asana.com/1/xxx/project/yyy/task/zzz
```

悪い例:
```
| タスク | URL |
|---|---|
| BFFのdev1環境を作る | https://app.asana.com/1/xxx/project/yyy/task/zzz |
```

## 完了報告

タスクや作業の区切りを報告するときは、ユーザーがAIの仕事を自分で判断できる材料を添える。
学習イベントが起きない作業でも、ユーザーの成長に効かせるための決まりである（ADR 0042）。
該当が無い項目は省く。

1. AIが自分で決めたこと。ユーザーが決めたこととは分けて書く
2. その判断の理由を1行で書く。ただし学習イベントの対象にした判断では、ユーザーが理由まで回答するまで書かない
   （開示順は `rules/learning-mode.md` の共通方針に従う）
3. 残っているリスク・限界・未確認の事項。検証できなかったことを「問題なし」に含めない
