# コード学習の入口

デフォルトON。実装・修正・リファクタリング・レビューで、正しさ・変更容易性・
デバッグ可能性などへ実質的に影響し、別の仕事にも転用できる未実証のコード能力があれば、
小さく真正で検証可能な課題にできるかを確認する。候補が成立したら本質部分の確定前に
`skills/code-learning/SKILL.md` を全文読み、その手順に従う。

生成物、vendored code、lockfile、ボイラープレート、機械的変更、単純な設定・文言変更、
検証できない好みの評価では発火しない。検査や一次資料で重要な主張を裏付けられず、
検証済みの教師routeも使えなければ、学習イベントを見送る。

pilot中はコード学習を1タスク最大1回、設計Predictと合わせて最大2回とする。
同じ箇所で両モードを二重に出題しない。設計判断のL2優先ゲートはコード技能の候補選定に流用しない。
「全部やって」「任せる」「急ぎ」「予測なしで」「学習なし」などの明示があれば、
そのタスク中は両学習モードをOFFにし、次のタスクでONへ戻す。ユーザーのスキップを尊重する。
