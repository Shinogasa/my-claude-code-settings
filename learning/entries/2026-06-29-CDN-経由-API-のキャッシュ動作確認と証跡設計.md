# CDN 経由 API のキャッシュ動作確認と証跡設計


**問いかけ:** なぜ `x-cache: Hit` だけでなく `Age` ヘッダも証跡に含める設計にしたのか。`x-cache: Hit` だけでは何が不十分か。

**自分の説明:**
Age の値でキャッシュの鮮度がわかるから参考になる、という話。

**補足:**
方向性は正しい（Age = キャッシュされてからの経過秒数 = 鮮度指標）。
証跡としてもう一歩踏み込むと、Age が回を追って単調増加していることで
「同一のキャッシュエントリが時間経過とともに使い回されている（＝キャッシュが永続している）」
ことの裏付けになる。`x-cache: Hit` は「ヒットした」事実しか示さず、理屈上は毎回作り直しても
Hit と出うるため、Age の単調増加が "本当にキャッシュが効いている" ことの傍証として効く。
