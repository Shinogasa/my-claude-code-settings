# 誰も気づけない状態の検査をどこに置くか

## 判断点

コンテナ運用の仕組みに、次の3種類の「今は誰も気づけない状態」を検出する検査を
追加しようとしていた。

- 上流の共通設定が前提を変えたこと（volume 名・環境変数）
- 認証情報のpathを指定したのに、実体が空のまま起動していること
- 異常終了で残った一時ディレクトリが蓄積していること

3つとも置き場所の選択肢が同じ形をしていたため、1つの判断としてまとめた。

選択肢:

- A) 毎操作の preflight として起動コマンド側で落とす
- B) degraded reason として起動完了マーカーへ載せる
- C) セットアップスクリプトの実行時にだけ検査する

選んだ結論: **B**

判断基準（原文）:

> Aだと毎回止まって改善しないといけないから作業が滞りそう。警告を出して余裕のある
> タイミングまたは優先的に対応が必要と判断したタイミングで実施が良い。
> がこれだとdoctorとかしないと気が付かない？

## 実際

結論は一致。そして最後の疑問は正しく、**想定より悪かった**。

healthcheck は marker の status が `ready` でも `degraded` でも通す実装だった。
つまり degraded でも healthcheck は 0 を返す。結果:

- コンテナ一覧は **healthy** と表示する
- 起動コマンドの `--wait` は healthy を待つので、degraded でも黙って成功する
- 「診断コマンドを叩かないと気づかない」ではなく、**積極的に「問題なし」と表示される**

## 差分

一致。予測に含まれていなかった観点は
「**観測可能にすること（pull）と、気づかせること（push）は別の作業**」。

B は観測可能性を確保するが、push の経路を1本も追加しない。
診断コマンドを叩く人がいるという前提に全部乗っている。

対象リポジトリは**同じ問題を一度解いていた**。別の検査スクリプトが対話シェルの
起動ファイルへ警告を追記しており、その理由が
「起動時ログは exec したシェルに流れないため、対話シェルでも再検査する」だった。
README も「『鳴らす』と『気づかれる』は別問題」と明記していた。
今回の degraded reason には、その push が付いていなかった。

## 評価

**全軸充足**。

- **トレードオフ** — A を捨てて何を得たか（作業の継続性）と何を失ったか（即時の強制）を
  両方言えている
- **失敗モード** — B の壊れ方を自分で特定している（気づかれない）
- **前提の検証** — 断定せず疑問形で出している。「知らないこと」を「知っている」に畳んでいない

### 基準が破れる条件

「止めずに警告し、余裕のあるタイミングで対応する」が成立するのは、
**劣化状態が不活性なとき**だけ。

| 対象 | 劣化状態を放置すると |
|---|---|
| 空の認証情報 | 該当CLIが失敗するだけ。不活性 → 後回し可 |
| 孤児ディレクトリ | ディスクを少し食うだけ。不活性 → 後回し可 |
| **上流の前提変更** | 別の永続領域へ状態を書き続ける。後回しにした期間分、間違った場所に認証とsessionが積む |

3つ目だけは後回しが損失を積む側にある。判断基準そのものは正しく、
**この項目がその基準の境界線上にある**という構造だった。

## 過去の判断原則との接続

`2026-08-19-hook承認をセットアップの警告にする-4.md` に、今回そのまま当たる原則が既にあった。

> 「人間の後続操作が行われなかった場合、その未完了状態はどこで再通知されるか」を決める。

「診断コマンドを叩かないと気づかない？」という疑問は、この原則へ自力で到達している。
前回は指摘された側だった問いを、今回は自分から出した形になった。

## 概念

**push 型監視と pull 型監視** — 状態を「見に行けば分かる」ようにするのが pull、
「向こうから目に入る」のが push。pull だけの仕組みは、
見に行く人がいるという前提に依存する。

## 定石

degraded を出す操作は、その操作の最後に理由を stderr へ列挙する。
healthcheck の戻り値だけに載せると、コンテナ一覧が healthy を表示するため、
状態が観測可能でも誰の目にも入らない。

## 次の問い

**次に同種の判断で確認する問い**: 検査を degraded / warning として置くときは、
「その報告が**誰のどの操作で目に入るか**」を1本決める。決められないなら、
それは観測可能にしただけで気づかれる仕組みにはなっていない。
