# 個人 ChatGPT アカウントのセッションで有効にする MCP サーバ名。
#
# `~/.codex/config.toml` は会社の設定であり、個人プロファイルはその上に merge される。
# ここに書かれていないサーバは setup.sh が `enabled = false` で生成する（deny by default）。
#
# 会社設定に新しい MCP サーバが増えたとき、既定で個人セッションへ引き継ぐと
# 会社のゲートウェイ・会社の鍵・会社のワークスペースを個人作業から叩くことになる。
# しかもエラーも通知も出ないため、起きたことに気づく契機が無い。
# 「不要なら後で切る」が成立しないので、明示的に許可するまで無効にする。
#
# 1行1サーバ名。`#` 始まりはコメント（行末のインラインコメントは使えない）。
#
# ここへ足すサーバが `url` / `http_headers` / `bearer_token_env_var` を持つ場合、
# それは外部へ接続する。会社のゲートウェイ上にあるなら足してはいけない。
# setup.sh は生成時に該当するものを警告するが、止めはしない（個人のリモートサーバを
# 使う正当な場合があるため）。判断はここを編集する人が持つ。
